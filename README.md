# My AHK Script

## Description

This is a comprehensive AutoHotkey (AHK) script for Windows, designed to enhance productivity and streamline various tasks through custom hotkeys and automation.

## Features

- **Application Toggling**: Quickly switch between applications or launch new instances.
- **Custom Hotkeys**: Utilize CapsLock as a modifier key for various actions.
- **Window Management**: Easily manipulate window sizes and positions.
- **Text Manipulation**: Perform operations like case switching, line duplication, and more.
- **System Controls**: Adjust volume, control media playback, and manage system settings.
- **Auto Dark Mode**: Automatically switch between light and dark modes based on time.
- **Clipboard Enhancement**: Separate clipboard functionality for improved text handling.
- **Browser Integration**: Open links, perform searches, and manage browser windows efficiently.
- **Gaming Environment**: Toggle specific settings for an optimized gaming experience.

## Key Bindings

For a complete list of keybindings, please refer to the `common/constants/keybindings.ahk` file.

## Requirements

- AutoHotkey v2.0 or later
- Windows operating system

## Installation

1. Install AutoHotkey v2.0 or later from the [official website](https://www.autohotkey.com/).
2. Clone this repository or download the script files.
3. Run the `main.ahk` file to start the script.

## Configuration

You can customize various settings in the following files:

- `common/constants/settings.ahk`: General script settings
- `common/constants/applications.ahk`: Application paths and window dimensions

## Usage

After running the script, use the defined hotkeys to access various functions.

Press `LAlt + /` to toggle the help window for a quick reference of available commands.

Press `CapsLock + /` to toggle the help window for a quick reference for Capslockplus hotkeys.

## Additional Features

- **Admin Script**: Some functions require administrative privileges and are handled by a separate admin script.
- **Scheduled Tasks**: The script includes functionality for scheduled tasks, such as auto dark mode switching.
